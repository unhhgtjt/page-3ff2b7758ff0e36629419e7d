隔壁西站

隔壁西站官方网站提供机场订阅、VPN 梯子网络加速与多端客户端下载指引。我们把稳定线路、清晰套餐和可落地的导入步骤放在同一页，方便你按设备完成订阅与连接。

品牌简介

隔壁西站定位为面向个人与小团队的机场服务。名称取自「西站」这一交通枢纽意象：把常用地区的入口集中起来，用统一订阅分发到 Clash、Shadowrocket、v2rayN 等客户端。本站即官方站点，用于说明套餐边界、客户端选择与导入流程，不托管来路不明的安装包。

线路侧覆盖香港、台湾、日本、新加坡、美国与部分欧洲入口，旗舰与团队套餐包含 IPLC 专线游戏优化节点。流量按自然月重置，同时在线设备数按套餐限制。我们不公布虚构评分，也不把第三方评论当作卖点；是否适合你，取决于设备数量、流媒体需求和是否需要游戏低延迟。

使用场景

流媒体与长视频

基础版可满足常见站点的基础解锁；旗舰版强调全节点原生流媒体能力，适合长时间 1080P/4K 播放与多地区内容切换。建议优先选择标注流媒体的节点，并在客户端开启规则分流，避免国内流量绕行。

游戏与实时语音

对延迟敏感的对战与语音，优先使用旗舰版 IPLC 专线。连接后在客户端查看当前延迟与丢包，必要时切换同区域备用节点。团队版适合战队或工作室多设备同时在线。

远程办公与开发

代码仓库、文档协作、跨境会议可通过分流规则只代理必要域名。团队版支持更高并发与定制路由，适合把办公网段和娱乐流量分开。

学术检索与资料同步

论文库、预印本与国际网盘同步对稳定性要求高于极限带宽。建议使用旗舰节点池并保留一条备用线路，避免单一入口拥塞时中断下载。

客户端选择

隔壁西站采用通用订阅链接，不绑定单一闭源壳客户端。官方建议：先确定系统，再选维护活跃、支持订阅转换的程序，最后在用户中心复制订阅地址导入。本页强调客户端选择，是因为同一套餐在不同程序里的分流、TUN 与规则质量差异很大。

Windows

日常推荐 Clash Verge 或 v2rayN。前者图形规则清晰，后者对多种内核兼容好。下载请走应用官方渠道，导入订阅后开启系统代理或 TUN，再按域名规则分流。

macOS

轻量需求可用 ClashX 系；需要策略组与网界面板时考虑 Surge。导入订阅后检查 DNS 与 Fake-IP 设置，避免国内应用被全局带走。

Android

Clash Meta 系与 v2rayNG 覆盖大多数机型。注意省电策略不要杀掉后台 VPN。若需要分应用代理，优先选支持按包名分流的客户端。

iOS 与 iPadOS

Shadowrocket、Stash、Quantumult X 均为常见选择。请从正式商店获取，导入后更新资源与规则。iOS 对配置描述文件较敏感，不要混用多个互相冲突的 VPN 配置。

Linux 与路由器用户可使用 clash / sing-box 订阅。团队版若需落地网关，把订阅交给一台常开设备做旁路网关，比每台终端单独拨号更省设备额度。

操作说明

  1. 在隔壁西站官网选择套餐并完成订阅，进入用户中心复制通用订阅链接。链接属于账号凭证，不要公开张贴。
  2. 按上一节选择与系统匹配的客户端，仅从开发者站点或应用商店安装，避免来路不明的「一键包」。
  3. 在客户端选择「从 URL 导入 / 订阅」，粘贴链接并更新节点。若程序需要类型，选择 Clash 或通用订阅即可。
  4. 打开规则模式而非无脑全局：国内直连、国际代理。游戏与会议可临时切到对应区域节点。
  5. 连接后访问需要加速的站点验证。若失败，先更新订阅、更换同区域节点，再检查系统时间与 DNS。
  6. 多设备共用时不要超过套餐在线上限。更换设备先在旧设备断开，再在新设备连接。

官方下载相关说明只覆盖「去哪里选客户端」和「如何导入」，不提供来源不明的安装文件镜像。若客户端无法识别订阅，核对链接完整性后改用 Clash 配置再试。

常见问题

隔壁西站是不是官方机场？如何确认官网？

是。本页为隔壁西站官方网站内容页，用于公布套餐、客户端选择与导入步骤。认准站点标识与用户中心订阅入口，不要通过来路不明的第三方「代充」获取链接。

客户端应该去哪里下载？你们提供安装包吗？

请在各客户端的官方页面或应用商店下载 Clash、v2rayN、Shadowrocket 等程序。隔壁西站不托管安装包，以降低篡改风险。官方下载在本语境下指「按官网指引选择正版客户端」，而不是把所有二进制都放在同一压缩包里。

三个套餐怎么选？流量和设备不够会怎样？

单人轻度浏览选基础版；需要原生流媒体、游戏专线或优先工单选旗舰版；工作室或多终端选团队版。流量用尽或设备超限会导致新连接失败或降速，此时应升级档位或等待月度重置，而不是反复重连占用会话。

节点覆盖哪些地区？游戏加速有什么区别？

常规覆盖包括香港、台湾、日本、韩国、新加坡、美国与部分欧洲入口。旗舰版增加 IPLC 专线游戏优化，团队版另有 VIP 高带宽节点。游戏场景请固定区域、关闭多余规则探测，并把语音与对战走同一出口。

是否记录上网内容？出问题如何反馈？

浏览内容不作为日志保存。仅在排障所需范围内保留连接元数据。基础版走常规工单；旗舰版提供 7x24 优先工单；团队版另有专属客户经理通道。反馈时请带上客户端名称、操作系统和订阅更新时间，便于对照节点状态。

订阅链接泄露了怎么办？可以在路由器上使用吗？

立即在用户中心重置订阅。重置后旧链接失效，需在所有客户端重新导入。路由器或旁路网关可以使用同一订阅，但会计入设备在线数，团队版更适合这种部署。
